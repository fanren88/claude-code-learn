跟着本页走完，你就能在终端里用上 Claude Code。

## 开始前准备

- 已打开终端（不熟悉可先搜「终端入门」）
- 有一个代码项目目录
- 拥有 [Claude 订阅](https://claude.com/pricing)（Pro / Max / Team / Enterprise）、[Console](https://console.anthropic.com/) 账号，或企业云提供商访问权限

## 第 1 步：安装

若尚未安装，见 [安装](/start/install/)。最快方式（macOS / Linux）：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

## 第 2 步：登录

```bash
claude
```

首次运行会提示登录。也可在会话内输入：

```
/login
```

## 第 3 步：进入项目并提问

```bash
cd /path/to/your/project
claude
```

在提示符下用自然语言提问，例如：

```text
what does this project do?
```

或中文：

```text
这个项目是做什么的？用中文回答
```

## 第 4 步：第一次改代码

```text
add a hello world function to the main file
```

Claude 会：

1. 找到合适文件
2. **展示拟议修改**
3. 等你批准
4. 写入文件

:::tip
默认每次改文件都会询问。可在会话中开启「Accept all」以加快迭代，但新手建议先逐条批准。
:::

## 第 5 步：试试 Git

```text
what files have I changed?
```

```text
commit my changes with a descriptive message
```

## 常用命令

| 命令 | 作用 |
|------|------|
| `claude` | 进入交互模式 |
| `claude "fix the build"` | 一次性任务 |
| `claude -p "explain foo"` | 问完即退出 |
| `claude -c` | 继续当前目录最近会话 |
| `/help` | 查看斜杠命令 |
| `exit` 或 Ctrl+D | 退出 |
