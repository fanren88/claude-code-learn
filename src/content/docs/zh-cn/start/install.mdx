## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | macOS 13+、Windows 10 1809+、Ubuntu 20.04+、Debian 10+、Alpine 3.19+ |
| 内存 | 4 GB 及以上 |
| 架构 | x64 或 ARM64 |
| 网络 | 需要联网 |

## Homebrew（macOS）

```bash
brew install --cask claude-code
```

- `claude-code`：稳定通道
- `claude-code@latest`：最新通道

Homebrew **不会**自动更新，需手动：`brew upgrade claude-code`

## WinGet（Windows）

```powershell
winget install Anthropic.ClaudeCode
```

需手动：`winget upgrade Anthropic.ClaudeCode`

## Linux 包管理器

Debian / Ubuntu、Fedora / RHEL、Alpine 等可用 apt、dnf、apk 安装，详见[官方 Setup](https://code.claude.com/docs/en/setup)。

## 验证安装

```bash
claude --version
```

## 常见问题

**命令找不到 `claude`**

- 重启终端，或把安装目录加入 `PATH`
- Native 安装后按终端提示执行 `source` 相关配置

**Windows 上 Bash 不可用**

- 安装 Git for Windows，或在 WSL 内使用 Claude Code
