title: FAQ
description: Install, login, and permissions
---

**`claude` not found?** Restart the terminal and check PATH from the install script.

**Login issues?** Try `/login` and verify network/proxy settings.

**Too many prompts?** Adjust permission mode (`Shift+Tab`) or `settings.json` carefully.

**Wrong edit?** Use `git checkout -- <file>` or ask Claude to revert.

Authoritative answers: [official troubleshooting](https://code.claude.com/docs/en/troubleshooting).
