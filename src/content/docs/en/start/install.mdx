## Requirements

- macOS 13+, Windows 10 1809+, Ubuntu 20.04+, or equivalent  
- 4 GB+ RAM, x64 or ARM64  
- Internet connection

## Native (recommended)

**macOS / Linux:**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

## Homebrew / WinGet

```bash
brew install --cask claude-code
```

```powershell
winget install Anthropic.ClaudeCode
```

Native installs auto-update; Homebrew and WinGet require manual upgrades.

## Verify

```bash
claude --version
```
