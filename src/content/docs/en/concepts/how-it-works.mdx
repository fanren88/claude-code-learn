1. You describe a goal in natural language  
2. Claude plans steps and uses tools (read files, search, run commands)  
3. Sensitive actions pause for your approval  
4. The loop continues until done or you stop  

See [Tools & permissions](/en/concepts/tools-and-permissions/) and [Context](/en/concepts/context/).
