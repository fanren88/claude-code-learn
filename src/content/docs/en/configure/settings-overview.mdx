  <figcaption>Settings decide the default behavior; permission rules decide whether a tool is allowed, reviewed, or blocked.</figcaption>
</figure>

| Level | Location | Controlled by |
|-------|----------|---------------|
| Managed | Org policy | Admin |
| Project | `.claude/settings.json` | Team |
| User | `~/.claude/settings.json` | You |
| Local | `.claude/settings.local.json` | You (gitignored) |

Use `/config` in a session for interactive editing.
