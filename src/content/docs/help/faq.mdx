## 安装后找不到 `claude` 命令？

1. 关闭并重新打开终端  
2. 检查安装脚本输出的 PATH 提示  
3. 尝试 `which claude`（macOS/Linux）

## 登录失败或反复要求登录？

- 确认网络可访问 Anthropic 服务  
- 使用 `/login` 重新授权  
- 企业环境检查代理与防火墙

## 一直弹权限确认，太慢？

- 会话内可切换权限模式（`Shift+Tab`）  
- 在 `settings.json` 中调整 `permissions.allow`（需谨慎）

## Claude 改错文件了怎么办？

- 使用 Git：`git checkout -- <file>`  
- 若未提交，也可让 Claude：`revert the last change to <file>`

## 与官方文档不一致？

以 [code.claude.com](https://code.claude.com/docs/en/quickstart) 为准；本站页脚有 Last verified 日期。
