## 如何贡献链接

编辑仓库中的 `src/data/articles.json`，按现有字段追加条目后提交 PR。

```json
{
  "id": "unique-id",
  "title": "文章标题",
  "url": "https://...",
  "author": "作者",
  "lang": "zh",
  "category": "practice",
  "level": "实践",
  "tags": ["入门"],
  "summary": "为什么值得读",
  "date": "2026-05-19",
  "tip": "可选读后提示"
}
```
